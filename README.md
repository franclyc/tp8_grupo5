# Trabajo Práctico N.° 8 – API REST

API REST en Java con Spring Boot para gestionar **Tickets** y **Empresas** (`/api/empresas`). Permite listar, consultar por id, crear, modificar y eliminar empresas. Los datos se guardan en colecciones en memoria.

## Herramientas
- Java
- Spring Boot (Spring Web)
- Maven
- Eclipse / Spring Tool Suite
- JSON y HTTP (GET, POST, PUT/PATCH, DELETE)
- Postman para probar los endpoints
